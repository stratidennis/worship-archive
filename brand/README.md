# Brand art

The source images, at the size they arrived. Everything under `packages/ui/public` and
`packages/desktop/build` is generated from these by `pnpm icons` — edit the art here and
re-run it, never the other way round.

| file                 | what it is                                      |
| -------------------- | ----------------------------------------------- |
| `logo-mark.png`      | The mark alone, cropped tight. Used in the app. |
| `logo-wordmark.png`  | Mark and name, cropped tight. For wide places.  |
| `logo-square.png`    | The mark on a square canvas, already margined.  |
| `favicon-source.ico` | The supplied favicon, kept for reference.       |

The blue is `#65b9fc`, which is close enough to the dark theme's `--color-chord` that
the mark sits naturally beside the interface's own accent.
